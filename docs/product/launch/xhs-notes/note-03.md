## 正文
```
拿到一张职业锚雷达图，只盯着最高分就太可惜了。分享我常用的 3 个读图方法（图中是示例数据，仅用来演示）：

① 看最高的 1–2 项
它们是你做取舍时的"底线需求"。选工作先问：这件事能不能满足我最高的那一两项？

② 看最低的项
低分不是缺点，只是说明它对你不是决定因素。但也别完全忽略，它可能在某个阶段冒出来。

③ 看差距和并列
前几名接近 → 几件事都重要，找能同时满足的环境；
一项遥遥领先 → 取舍时以它为准，其他可以让步。

最后提醒：分数是倾向，不是定论。状态、阶段、处境都会变，半年后再看，结果可能不一样，这很正常。

你的雷达图是什么形状？不用报分数，说形状就行，比如"一座山""两个高峰""比较平均"～
（仅作自我认知参考）
```
