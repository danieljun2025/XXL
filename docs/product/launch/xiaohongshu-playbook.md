# 小红书渠道作战手册（#29）

> 状态：草稿（已按规则核查结果修订）。小红书**只做内容与信任**，**不跨平台导流**：笔记里不出现闲鱼等任何他处信息。先读 [platform-rules-check.md](platform-rules-check.md)。
> 平台规则会变：商业推广、站外导流、测评类内容都有规范，**以 App 内规则中心的当前版本为准，先小范围试发，观察是否被提醒或限流，再放量。**

## 1. 定位
| 项目 | 内容 |
|---|---|
| 一句话定位 | 用职业锚帮你看清"我到底想要什么样的工作" |
| 目标读者 | 22–35 岁：应届生、刚工作几年的职场人、正在跳槽/转行/纠结 offer 的人 |
| 人设 | "把职业锚讲明白的朋友"：克制、真诚、有方法，不贩卖焦虑，不吹"神测" |
| 语气 | 口语、短句、具体场景；少用术语，用了就解释 |
| 昵称 | `【品牌名】`（简介和资料里不放他处账号） |
| 主页简介（≤ 2 行） | `用职业锚看清自己的职业动机｜40 题自测｜解读与行动建议` + 更新节奏（如"每周三更"） |
| 头像 | 简洁的雷达图或字母徽标，与封面风格一致 |

## 2. 四个内容支柱
| 支柱 | 占比 | 目的 | 例子 |
|---|---|---|---|
| ① 科普：8 种职业锚 | 30% | 建立专业感、搜索流量 | 每种职业锚一篇："技术型的人，为什么不想当领导？" |
| ② 场景：用职业锚做决定 | 30% | 贴近痛点、促进收藏 | 跳槽、转行、选 offer、要不要创业、被迫转管理 |
| ③ 自测体验与案例 | 25% | 转化主力：让人想测 | "我测了职业锚，结果让我愣住"；匿名并经本人同意的案例 |
| ④ 工具与清单 | 15% | 高收藏、可传播 | 决策表、问自己的 7 个问题、面试时怎么讲你的职业锚 |

## 3. 前 10 篇选题（可直接开写）
格式：标题 → 开头钩子 → 要点 → 行动引导（CTA）。

1. **《测完职业锚我才明白，我不是懒，是"安全型"》** → 钩子：为什么我总在跳槽边缘退回来？ → 安全型的特征/优势/盲区、3 个自查问题 → CTA：评论区告诉我，你觉得自己更像哪一种？
2. **《8 种职业锚一张图看懂》**（信息图） → 钩子：你最不愿放弃的是什么？ → 8 类各一句话 + 适合的环境 → CTA：收藏，对照自己；评论区说说你是哪一种。
3. **《被迫转管理很痛苦？可能你是"技术/职能型"》** → 钩子：升职了却不开心 → 技术型 vs 管理型的差别、折中办法 → CTA：评论区说说你的情况。
4. **《跳槽前先问自己这 5 个问题（职业锚版）》** → 钩子：薪资高了，为什么更累？ → 5 个问题 + 如何用结果筛 offer → CTA：收藏，下次跳槽前拿出来问自己。
5. **《自主型的人，为什么受不了"大厂流程"》** → 钩子：不是不努力，是被束缚 → 自主型的工作设计建议。
6. **《创业型 vs 打工人：你适合创业吗？》** → 钩子：别被"创业热"带跑 → 创业型的特征、小步试验法。
7. **《服务型/挑战型/生活方式型：容易被误解的 3 种人》** → 钩子：有人要意义、有人要难题、有人要生活。
8. **《我做了 40 题，雷达图长这样》**（自测体验） → 钩子：晒出（打码）报告图，讲 3 个"被说中"的点 → CTA：评论区聊聊：你最想被说中的是哪一点？
9. **《面试被问"你的职业规划"，职业锚怎么回答》** → 钩子：别再背模板 → 用主职业锚组织回答的模板。
10. **《给迷茫的毕业生：先别问"选什么"，先问"我看重什么"》** → 钩子：一个比专业更重要的变量 → 3 步用职业锚缩小选择范围。

## 4. 标题与封面
**标题公式**（≤ 20 字，口语）：
- 反常识：`测完才发现，我不是 ____，是 ____`
- 场景 + 解法：`被迫转管理？先看看你的职业锚`
- 清单：`跳槽前先问自己的 5 个问题`
- 对比：`技术型 vs 管理型，差别在哪`
- 避免：夸大（"一测就准"）、焦虑（"再不看就晚了"）、绝对化（"所有人都"）。

**封面规范**：3:4 竖图；一句大字（≤ 12 字）+ 一个简单图形（雷达图/色块）；同一套配色和字体，保持账号识别度；文字在手机缩略图下仍清晰。

**正文结构**：钩子（1–2 句）→ 要点（3–5 条，短句，可用序号）→ 一个自己的小观点 → 互动引导（收藏/评论）。

## 5. 发布节奏
- **每周 3 篇**（建议周二、周四、周日晚 8–10 点发布；这是起始假设，用数据校准）。
- 前两周：6 篇（支柱 ① ② 各 2 篇，③ ④ 各 1 篇），先养账号与测试平台反应。
- 每篇发布后 2 小时内**回复所有评论**，置顶一条补充评论（延伸问题或小清单）。
- 每周一复盘：看收藏率和评论，保留表现好的角度，砍掉没反应的。

## 6. 评论区与私信话术
**原则：不在平台内引导任何站外交易，也不暗示。** 只回答内容问题，把互动留在评论区。

| 场景 | 回复 |
|---|---|
| 问"在哪测 / 怎么买" | 「谢谢关注～这里主要分享职业锚的内容，欢迎收藏和评论交流」（**不指路、不提别的平台、不说"搜我同名"**） |
| 问"准吗" | 「它是帮你看清偏好的自我认知工具，题目是原创的，不是诊断，也不预测结果～」 |
| 问价格 | 不在这里聊价格：「这里不方便聊这个，抱歉～」 |
| 求解读 | 「可以把你想问的在评论区说说，我挑共性的问题写成笔记」 |
| 质疑/负面 | 不争辩，承认局限，感谢反馈 |
| 私信要联系方式 | 不交换联系方式；需要承接咨询时，**只用官方提供的组件**（开通专业号后，在 App 内核对） |

不做：好评返现、转发有礼、互相导流的小号配合、"主页有惊喜"之类暗示。

## 7. 转化路径（当前阶段：只做内容与信任）
**小红书不放任何指向别处成交的信息**（详见 [platform-rules-check.md](platform-rules-check.md)）。现阶段它的作用是：建立专业形象、积累关注与收藏、让读者自己知道"职业锚"这个词。读者想买，会在其他渠道自己搜到；我们不指路。

想在小红书直接成交，只有**官方路径**，上线前需要在 App 内核对开通条件：
| 选项 | 是什么 | 要先弄清楚 |
|---|---|---|
| A 小红书店铺 | 平台内开店、官方购物车 | 虚拟服务类目是否允许；是否需要营业执照；怎么发货 |
| B 官方留资/私信获客工具（专业号） | 在平台内合规收集咨询线索 | 开通条件；收集后能做什么、不能做什么 |
| C 暂不成交 | 只做品牌内容，成交靠闲鱼站内搜索 | 无需额外资质，最稳 |

建议从 **C** 开始，内容稳定、账号安全后再评估 A 或 B。

**用户分享自己的报告图（UGC）**：必须本人同意、姓名打码；不返现、不强制；图片里不能带其他平台的名称或水印。

## 8. 合规与风险（发布前逐条过）
- [ ] **没有任何他处信息**：笔记、封面、评论、私信、简介、头像里不出现闲鱼等其他平台名称、账号、店铺、链接、口令、二维码、截图、水印，也没有暗示（"搜我同名""私我"）
- [ ] 不出现"官方原版""权威""Schein 授权""保证""一定""100%""诊断""治疗""治愈"
- [ ] 定位为"职业动机自测、自我认知参考"，**不称"心理测试""心理咨询"**，不涉及心理健康治疗；解读叫"解读"，不叫"咨询"
- [ ] 如涉及商业推广，按平台要求使用相应账号类型或报备（以 App 内规则为准）
- [ ] 案例必须匿名并取得本人同意；不使用他人真实姓名、邮箱、聊天记录
- [ ] 图片不侵权（自制或有授权的素材）；引用理论只讲概念，不复制原版问卷和他人文章
- [ ] **不用多个账号互相点赞评论互动**；业务号与个人号不互相导流
- [ ] 收到提醒、限流或下架通知：24 小时内记录原因，调整写法，写入 `06-risks-and-compliance.md`，暂停放量
