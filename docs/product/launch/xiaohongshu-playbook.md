# 小红书渠道作战手册（#29）

> 状态：草稿。小红书负责**被看见和建立信任**，**成交仍在闲鱼**（见 `xianyu-listing-pack.md`）。
> 平台规则会变：商业推广、站外导流、测评类内容都有规范。**以小红书当前的社区规范和商业推广规则为准，先小范围试发，观察是否限流或被提醒，再放量。**

## 1. 定位
| 项目 | 内容 |
|---|---|
| 一句话定位 | 用职业锚帮你看清"我到底想要什么样的工作" |
| 目标读者 | 22–35 岁：应届生、刚工作几年的职场人、正在跳槽/转行/纠结 offer 的人 |
| 人设 | "把职业锚讲明白的朋友"：克制、真诚、有方法，不贩卖焦虑，不吹"神测" |
| 语气 | 口语、短句、具体场景；少用术语，用了就解释 |
| 昵称 | `【品牌名】`（与闲鱼店铺同名，方便用户找到） |
| 主页简介（≤ 2 行） | `用职业锚看清自己的职业动机｜40 题自测｜解读与行动建议` + 更新节奏（如"每周三更"） |
| 头像 | 简洁的雷达图或字母徽标，与封面风格一致 |

## 2. 四个内容支柱
| 支柱 | 占比 | 目的 | 例子 |
|---|---|---|---|
| ① 科普：8 种职业锚 | 30% | 建立专业感、搜索流量 | 每种职业锚一篇："技术型的人，为什么不想当领导？" |
| ② 场景：用职业锚做决定 | 30% | 贴近痛点、促进收藏 | 跳槽、转行、选 offer、要不要创业、被迫转管理 |
| ③ 自测体验与案例 | 25% | 转化主力：让人想测 | "我测了职业锚，结果让我愣住"；匿名并经本人同意的案例 |
| ④ 工具与清单 | 15% | 高收藏、可传播 | 决策表、问自己的 7 个问题、面试时怎么讲你的职业锚 |

## 3. 前 10 篇选题（可直接开写）
格式：标题 → 开头钩子 → 要点 → 行动引导（CTA）。

1. **《测完职业锚我才明白，我不是懒，是"安全型"》** → 钩子：为什么我总在跳槽边缘退回来？ → 安全型的特征/优势/盲区、3 个自查问题 → CTA：想知道自己是哪一种，主页可以自测。
2. **《8 种职业锚一张图看懂》**（信息图） → 钩子：你最不愿放弃的是什么？ → 8 类各一句话 + 适合的环境 → CTA：收藏，对照自己；想要完整报告看主页。
3. **《被迫转管理很痛苦？可能你是"技术/职能型"》** → 钩子：升职了却不开心 → 技术型 vs 管理型的差别、折中办法 → CTA：评论区说说你的情况。
4. **《跳槽前先问自己这 5 个问题（职业锚版）》** → 钩子：薪资高了，为什么更累？ → 5 个问题 + 如何用结果筛 offer → CTA：收藏；想系统自测看主页。
5. **《自主型的人，为什么受不了"大厂流程"》** → 钩子：不是不努力，是被束缚 → 自主型的工作设计建议。
6. **《创业型 vs 打工人：你适合创业吗？》** → 钩子：别被"创业热"带跑 → 创业型的特征、小步试验法。
7. **《服务型/挑战型/生活方式型：容易被误解的 3 种人》** → 钩子：有人要意义、有人要难题、有人要生活。
8. **《我做了 40 题，雷达图长这样》**（自测体验） → 钩子：晒出（打码）报告图，讲 3 个"被说中"的点 → CTA：想测的看主页。
9. **《面试被问"你的职业规划"，职业锚怎么回答》** → 钩子：别再背模板 → 用主职业锚组织回答的模板。
10. **《给迷茫的毕业生：先别问"选什么"，先问"我看重什么"》** → 钩子：一个比专业更重要的变量 → 3 步用职业锚缩小选择范围。

## 4. 标题与封面
**标题公式**（≤ 20 字，口语）：
- 反常识：`测完才发现，我不是 ____，是 ____`
- 场景 + 解法：`被迫转管理？先看看你的职业锚`
- 清单：`跳槽前先问自己的 5 个问题`
- 对比：`技术型 vs 管理型，差别在哪`
- 避免：夸大（"一测就准"）、焦虑（"再不看就晚了"）、绝对化（"所有人都"）。

**封面规范**：3:4 竖图；一句大字（≤ 12 字）+ 一个简单图形（雷达图/色块）；同一套配色和字体，保持账号识别度；文字在手机缩略图下仍清晰。

**正文结构**：钩子（1–2 句）→ 要点（3–5 条，短句，可用序号）→ 一个自己的小观点 → 引导（收藏/评论/想自测看主页）。

## 5. 发布节奏
- **每周 3 篇**（建议周二、周四、周日晚 8–10 点发布；这是起始假设，用数据校准）。
- 前两周：6 篇（支柱 ① ② 各 2 篇，③ ④ 各 1 篇），先养账号与测试平台反应。
- 每篇发布后 2 小时内**回复所有评论**，置顶一条补充评论（延伸问题或小清单）。
- 每周一复盘：看收藏率和评论，保留表现好的角度，砍掉没反应的。

## 6. 评论区与私信话术
| 场景 | 回复 |
|---|---|
| 问"在哪测" | 「主页简介里有，也可以在闲鱼搜【品牌名】」（**是否能这样写，先按平台当前规则小范围试，若被提示就改成只引导看主页**） |
| 问"准吗" | 「它是帮你看清偏好的自我认知工具，题目是原创的，不是诊断，也不预测结果～」 |
| 问"多少钱" | 「基础版价格在闲鱼商品页有写，首发期有优惠」 |
| 求解读 | 「可以先自测，结果出来后有解读版，会结合你的情况讲」 |
| 质疑/负面 | 不争辩，承认局限，感谢反馈；必要时私信了解具体问题 |

不在评论区和私信里发微信号、二维码、外部链接；不做"好评返现""转发有礼"等被平台限制的激励。

## 7. 转化路径与归因
```
小红书笔记 ──▶ 主页简介 ──▶ 闲鱼同名店铺/商品 ──▶ 下单拿兑换码 ──▶ 做测试 ──▶ 保存报告图 ──▶ （授权后）晒图回小红书
```
- **归因办法（不用写代码）**：为小红书建一个**渠道通用码**（后台 → 兑换码管理 → 通用码，备注"小红书 11 月"，设有效时长和人数上限），用「已使用 N / 上限」衡量带来的测试数。每个活动一个新码，互相不混。
- 可选的来源参数记录见 #30。
- **UGC**：鼓励买家分享**自己的报告图**，但必须本人同意、姓名打码；不返现，不强制。

## 8. 合规与风险（发布前逐条过）
- [ ] 不出现"官方原版""权威""Schein 授权""保证""一定""100% 准确"
- [ ] 定位为"自我认知参考/职业动机自测"，**不称心理测试、不做诊断、不涉及心理健康治疗**（测评类内容在平台上可能被更严格审核）
- [ ] 不留微信号、QQ、二维码、站外链接；导流写法先小范围试，按平台提示调整
- [ ] 如属于商业推广，按平台要求使用相应的账号类型或报备（以平台规则为准）
- [ ] 案例必须匿名并取得本人同意；不使用他人的真实姓名、邮箱、聊天记录
- [ ] 图片不侵权（自制或有授权的素材）；引用理论时只讲概念，不复制原版问卷和他人文章
- [ ] 发布后 24 小时内若收到提醒、限流或下架通知：记录原因，调整写法，并写入 `06-risks-and-compliance.md`

## 9. 指标与复盘
| 层级 | 指标 | 记录位置 |
|---|---|---|
| 曝光 | 笔记曝光、主页访问 | 小红书后台，每周手工记录 |

初始假设（上线 4 周后校准）：单篇收藏率 ≥ 3% 算合格；每周 3 篇坚持 8 周后再判断是否继续加大。
