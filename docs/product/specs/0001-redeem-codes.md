# PRD：兑换码（补写）

- 状态：已发布（v1.2.0，默认关闭）　Issue：（补写）　PR：#9　级别：L

## 问题
链接是公开的，买家可转发，卖一单可能被很多人免费使用；做一次分享活动时也需要「一个码大家都能用，但限时限人数」。

## 目标与指标
- 让每次测试都可控地发放和回收。
- 指标：已发出码的使用率；异常使用次数（护栏）。

## 范围
**做：** 一次性码（批量，可选有效期）；通用码（多人共用，可选有效时长和人数上限，每人限一次，可自定义码）；后台生成/复制/筛选/设置有效期/作废/导出；开关 `REQUIRE_CODE`。
**不做：** 在线支付、自动发码到买家（走闲鱼自动发货，见 #19）。

## 验收标准
- [x] 无码/无效码/已用/过期/已作废/名额满都被拒，且错误码不消耗任何码
- [x] 并发抢同一个码只有一人成功；通用码并发不超发
- [x] 已有未完成测试时继续作答不需要码、不重复扣码
- [x] 默认关闭，不影响线上行为

## 隐私与安全
码本身不含个人信息；兑换尝试按 IP 限速；码 8 位（去掉易混字符），通用码默认 6 位。

## 发布与回退
开关：`REQUIRE_CODE`（默认关）。回退：删除该变量。启用清单见 #15。
