# PRD：团队码与分团队报告（补写）

- 状态：开发完成，随 PR #11 待发布（目标 v1.3.0）　级别：L

## 问题
卖给公司、班级、培训营时，客户需要「一次发给一群人，只看这一群人的汇总」。现在所有数据在同一个后台，无法区分客户，也不能让客户自己看。

## 目标与指标
- 能创建团队、发团队码、让负责人自助查看汇总。
- 指标：团队成员完成率；达到 3 人汇总阈值所需天数；负责人是否回访。

## 范围
**做：** 团队管理页；团队码（归属团队的通用码/一次性码）；成员加入前知情同意；负责人凭团队报告码看汇总（`/team.html`）；管理员报表按团队筛选；记录与导出带团队列；团队关闭/重新开放/重新生成报告码；「负责人可看姓名」开关。
**不做：** 负责人看个人答案；团队内部分组；在线支付；给负责人发邮件。

## 隐私与安全（见 ADR-0007）
默认只看汇总；少于 3 人不显示；看姓名需显式开启并告知成员；报告码只显示一次、可重置、不是管理员口令；报告码尝试限速。

## 验收标准
- [x] 带团队码的答题记录归属该团队，报告里显示团队名
- [x] 负责人人数不足时看不到汇总，也看不到任何个人信息
- [x] 开启「看姓名」后才出现成员表，且不含邮箱
- [x] 重新生成报告码后旧码失效；报告码不能访问管理员接口
- [x] 关闭团队后不能再加入，但负责人仍可看报告
- [x] 没有团队、也未启用兑换码时，答题表单无任何变化

## 发布与回退
条件显示（存在开放团队或 `REQUIRE_CODE=1` 才出现码输入框）。回退：关闭团队或回滚 PR；数据库只加表加列，旧版本可运行在新库上。
