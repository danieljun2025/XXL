# ADR-0001：后端用 Node + SQLite，部署到 Render

- 状态：已采纳　日期：2026-10-24

## 背景
需要保存多人答题数据，纯静态站做不到。我没有 Supabase 账号，希望零外部依赖、一个人能维护。

## 备选方案
1. Supabase + GitHub Pages：免费额度够，但需要账号与较大改写。
2. Cloudflare Workers + D1：和域名同一家，但需重写。
3. **Node + SQLite（自带 node:sqlite）**：零依赖，一个文件存数据，容易备份。

## 决定
选 3，用 Docker 部署到 Render（Starter + 1GB 磁盘）。

## 后果
- 好处：简单、可本地完整运行、测试容易。
- 代价：只能单实例（带磁盘的服务不能横向扩展）；数据在单个文件里，必须做好备份（见 #14 #23）。
- 重新评估条件：并发持续超过数百人，或需要多实例。
